# A2 · 歷代曆法改革年表

**[简体中文](README.zh.md) ｜ 繁體中文 ｜ [English](README.md) ｜ [日本語](README.ja.md) ｜ [한국어](README.ko.md)**

## 這是什麼

中國歷史上 **52 部主要曆法**的行用年表，自上古**古六曆**起，經《太初曆》《大明曆》《戊寅元曆》《授時曆》，至清《時憲曆》與公元紀年。

## 文件

| 文件 | 說明 |
|:---|:---|
| `data/calendar_reforms.csv` | 主表，52 行 |
| `data/kaoyi_discrepancies.csv` | 考異表，4 處來源分歧 |

## 字段

| 字段 | 含義 |
|:---|:---|
| `序号` | 1—52，按行用年代先後 |
| `历法名` | 曆法名稱 |
| `朝代_政权` | 頒行或行用的朝代／政權 |
| `行用起年` / `行用止年` | 原樣寫法，公元前作「前104」 |
| `行用起年_数值` / `行用止年_数值` | 純整數年，**公元前為負數**（前 104 年 ＝ `-104`） |
| `主要编者` | 主持編制者 |
| `岁实_回归年_日` | 該曆採用的回歸年長度（日） |
| `朔望月_日` | 該曆採用的朔望月長度（日） |
| `岁首_斗建` | 歲首所在之月（建子／建丑／建寅／建亥） |
| `重大改动` | 該曆的關鍵貢獻；★ 標出五次大改革 |
| `依据` | 該行數據的來源 |

## 五次大改革

| 次 | 曆法 | 時間 | 改了什麼 |
|:--:|:---|:---|:---|
| 一 | 太初曆（鄧平、落下閎） | 前 104 年 | 以正月為歲首；首次把二十四節氣編入曆法；定「無中氣之月為閏月」 |
| 二 | 大明曆（祖沖之） | 463 年 | 首次在曆法中引入**歲差** |
| 三 | 戊寅元曆（傅仁均） | 619 年 | **始用定朔**（此前用平朔） |
| 四 | 授時曆（郭守敬、王恂） | 1281 年 | 廢上元積年；三次差內插法；弧矢割圓術 |
| 五 | 崇禎曆書 → 時憲曆 | 1645 年 | **正式採用定氣注曆**（平氣改定氣） |

> 「五次大改革」的編號各版本略有出入（有的把《崇禎曆書》算第五次，有的只算三次）。採用「五次」說時宜註明出處。

## 歲首（斗建）怎麼看

《史記·曆書》：「夏正以正月，殷正以十二月，周正以十一月。」

| 朝代 | 建 | 歲首相當於今農曆 |
|:---|:---|:---|
| 夏 | 建寅 | 正月 |
| 商（殷） | 建丑 | 十二月 |
| 周 | 建子 | 十一月 |
| 秦 | 建亥 | 十月 |

**太初曆（前 104）以後，一律建寅。**

## 兩處重要提醒

1. **歲實列只收錄有權威來源者（11 / 52 行）**，其餘留空。**留空不等於 0，也不等於該曆沒有歲實值**——它表示該數值在本次編纂所依據的公開材料中未查到可靠來源。**不以推測填補。**
2. **行用年是編纂值，不是原始文獻的直抄**。兩處公開年表源（維基「中國曆法」年表與百度百科《曆法》列表）在若干條目上不一致，已全部列入 `data/kaoyi_discrepancies.csv`，**並列兩說而不給結論**。**引用具體年份前請先查考異表。**
