# A2 · 歴代暦法改革年表

**[简体中文](README.zh.md) ｜ [繁體中文](README.zh-Hant.md) ｜ [English](README.md) ｜ 日本語 ｜ [한국어](README.ko.md)**

## これは何か

中国史上 **52 部の主要な暦法**の行用年表である。上古の**古六暦**に始まり、『<ruby>太初暦<rt>たいしょれき</rt></ruby>』『大明暦』『戊寅元暦』『<ruby>授時暦<rt>じゅじれき</rt></ruby>』を経て、清の『<ruby>時憲暦<rt>じけんれき</rt></ruby>』と西暦紀年に至る。

## ファイル

| ファイル | 説明 |
|:---|:---|
| `data/calendar_reforms.csv` | 主表、52 行 |
| `data/kaoyi_discrepancies.csv` | 考異表、出典の不一致 4 か所 |

## フィールド

| フィールド | 意味 |
|:---|:---|
| `序号` | 1—52。行用年代の順 |
| `历法名` | 暦法の名 |
| `朝代_政权` | 頒行または行用した王朝／政権 |
| `行用起年` / `行用止年` | 原表記のまま。紀元前は「前104」 |
| `行用起年_数值` / `行用止年_数值` | 純粋な整数年。**紀元前は負数**（前 104 年 ＝ `-104`） |
| `主要编者` | 編纂を主宰した者 |
| `岁实_回归年_日` | その暦が採用した回帰年の長さ（日） |
| `<ruby>朔望月<rt>さくぼうげつ</rt></ruby>_日` | その暦が採用した朔望月の長さ（日） |
| `岁首_斗建` | 年首の置かれた月（建子／建丑／建寅／建亥） |
| `重大改动` | その暦の鍵となる貢献。★ は五大改革 |
| `依据` | その行のデータの出所 |

## 五大改革

| 回 | 暦法 | 時期 | 何を変えたか |
|:--:|:---|:---|:---|
| 一 | 太初暦（鄧平・落下閎） | 前 104 年 | 正月を年首とする。二十四節気を初めて暦法に組み込む。「中気を含まない月を閏月とする」を定める |
| 二 | 大明暦（祖沖之） | 463 年 | 暦法に初めて**歳差**を導入 |
| 三 | 戊寅元暦（傅仁均） | 619 年 | **定朔を用いる**（それ以前は平朔） |
| 四 | 授時暦（郭守敬・王恂） | 1281 年 | 上元積年を廃す。三次差内挿法。弧矢割円術 |
| 五 | 『<ruby>崇禎暦書<rt>すうていれきしょ</rt></ruby>』 → 時憲暦 | 1645 年 | **<ruby>定気<rt>ていき</rt></ruby>注暦を正式に採用**（<ruby>平気<rt>へいき</rt></ruby>を定気に改める） |

> 「五大改革」の数え方は版によって少し異なる（『崇禎暦書』を五回目に数えるものもあれば、三回だけとするものもある）。「五回」説を採るときは出所を明記するのがよい。

## 年首（斗建）の見方

『史記』暦書：「夏の正は正月を以てし、殷の正は十二月を以てし、周の正は十一月を以てす。」

| 王朝 | 建 | 年首に当たる今の農暦 |
|:---|:---|:---|
| 夏 | 建寅 | 正月 |
| 商（殷） | 建丑 | 十二月 |
| 周 | 建子 | 十一月 |
| 秦 | 建亥 | 十月 |

**太初暦（前 104）以後は、一律に建寅。**

## 二つの重要な注意

1. **<ruby>歳実<rt>さいじつ</rt></ruby>の列は、権威ある出所のあるものだけを収める（11 / 52 行）**。残りは空欄とする。**空欄は 0 ではなく、その暦に歳実の値が無いということでもない**——今回の編纂が依拠した公開資料の中に、信頼できる出所が見つからなかったことを意味する。**推測で埋めない。**
2. **行用年は編纂値であって、原資料からの直写しではない**。二つの公開年表の出所（ウィキペディア「中国历法」年表と百度百科『历法』の一覧）は幾つかの項目で一致せず、すべて `data/kaoyi_discrepancies.csv` に収め、**二説を並置して結論は与えない**。**具体的な年を引用する前に、まず考異表を見られたい。**

| 区分 | 出所 |

| 五大改革 | 上記各出所の総合 |
