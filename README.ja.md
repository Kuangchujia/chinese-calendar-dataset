## II、A1 · 二十四節気の交節時刻

**定義**：**GB/T 33661-2017『農暦の編算と頒行』**による——二十四節気とは、太陽の地心視<ruby>黄経<rt>こうけい</rt></ruby>が 15° の整数倍に達する**瞬間**である。

**フィールド**：`year` · `term_index`（1–24）· `term` · `solar_longitude_deg` · `beijing_date` · `beijing_time` · `utc_date` · `utc_time` · `jd_utc`

**アルゴリズム**：太陽の地心視黄経は JPL DE421 星暦（パブリックドメイン）と Skyfield（MIT ライセンス）から計算し、その時点の真黄道（`ecliptic_latlon(epoch="date")`）を用い、根を二分法で秒まで求める。

**精度と検証**：紫金山天文台『2026 年暦日資料』が公布した 24 の公式値と逐項比較——

| 指標 | 結果 |
|:---|:---|
| 最大偏差 | **30 秒** |
| 平均偏差 | **11.4 秒** |
| 分に丸めた後の一致 | **24 / 24** |

> **使い方**：公式暦との完全一致が必要な場合は、紫金山天文台が公布した値を取られたい。本データが提供するのは**長い跨度（153 年）、秒級の精度、完全に公開され再現可能な算法**である。

**上限が 2052 年である理由**：JPL DE421 星暦は 1899-07-28 から 2053-10-08 まで（実測：2053-12-31 はすでに範囲外）。表全体を外挿なしで星暦内に内挿するため、上限を 2052 年とする。

**A2/A3 の節気フィールド**も本表から取る（A3 の「現行節気／節気月」は A1 のデータから結合する）。

## III、A2 · 歴代暦法改革年表

**内容**：52 部の暦法それぞれについて——**行用された年、主たる編者、その年首（月建の支）、主要な変更**——を記し、**五大改革**（太初 → 大明 → 戊寅元 → 授時 → 時憲）に標を付す。

**フィールド**：`序号` · `历法名` · `朝代_政权` · `行用起年` · `行用止年` · `行用起年_数值` · `行用止年_数值` · `主要编者` · `岁实_回归年_日` · `<ruby>朔望月<rt>さくぼうげつ</rt></ruby>_日` · `岁首_斗建` · `重大改动` · `依据`

**数値列について**：`_数值` 列は素の整数年を持ち、紀元前は負数で示す（例「前 104 年」＝ `-104`）。プログラムで扱いやすくするためである。

**<ruby>歳実<rt>さいじつ</rt></ruby>列は、権威ある出所のある値のみを記す（52 行のうち 11 行）**。残りは空のままにし、**推測で埋めない**。空白そのものが情報である——この編纂で参照した公開資料の中に、信頼できる出所まで辿れなかったという意味であり、ゼロという意味ではない。

**異文**：`data/kaoyi_discrepancies.csv` は**出所が食い違う 4 点**（例：<ruby>太初暦<rt>たいしょれき</rt></ruby>が行用を止めた年、大明暦の起年、淳熙暦と会元暦の年、<ruby>授時暦<rt>じゅじれき</rt></ruby>の起年）を記す。二つの読みを本表の扱いと並置し、**判定は下さない**。

## IV、A3 · 干支紀日対照表

**内容**：1900 年から 2052 年までの逐日について——**その日の干支の対・その干支番号（1–60）・その旬・現行の節気・節気月（月建の支）**——に加え、次の節気の名とその瞬間。

**干支紀日をグレゴリオ暦に整列できる理由**：干支の日数は、**商代から途切れずに続く連続六十日の循環**であり、月相にも太陽の位置にも結びつかない。したがって**一つの**アンカー日を定めれば、その全体が一意に決まる。

**整列のアンカー**：**1949-10-01 ＝ 甲子の日**（三つの出所が一致：百度百科「甲子日」項、複数の万年暦サイト、八字教材の作例）。このアンカーは近現代にあり、暦の換算にまつわる曖昧さを伴わない。

**交差検証（`data/verification_anchors.csv`）**：

| 日付 | 出所の記載 | 本表の数え | 結果 |
|:---|:---:|:---:|:---|
| 1590-12-22 | 甲子 | 甲子 | 一致 |
| 1861-11-11 | 甲子 | 甲子 | 一致 |
| **1949-10-01** | 甲子 | 甲子 | **整列アンカー** |
| 2025-12-21 | 甲子 | 甲子 | 一致 |
| **紀元前 720 年 02-22** | **己巳** | **己巳** | **一致** |
| 1965-12-22 | 甲子 | 庚戌 | ❌ その出所を誤りと判定（下記） |

**必ず述べておくべき二点**：

1. **古典のアンカーは自己整合的である——強い検証になる。** 『春秋』の魯隠公三年の項、「二月、己巳の日、日に食あり」は、日付を明記した中国最初の日食記録である。そのユリウス暦日付を逆算すると**紀元前 720 年 2 月 22 日**、本表が独立に数えると**己巳**で、記録と完全に一致する——**整列アンカーと 2,669 年の跨度で自己整合的**であり、これは途切れない六十日の循環という前提が成り立つことを示す。
   > ⚠ **再計算の際は紀年法に注意**：紀元前 720 年は**天文学的紀年 −719** に当たる（紀元 0 年はない）。−720 から数えると全体的に一日ずれ、誤った結論になる。

2. **一つの出所は誤りであり、そのように標す。** 公開資料に見える「1965-12-22 は甲子の日」という主張は、本表では**庚戌**と数える（1965 年 12 月に甲子の日はなく、最も近いのは 1966-01-05）。**本表はその記載のためにアンカーを調整していない。**

**1582 年の暦の切り替え**：グレゴリオ暦は 1582-10-15 から用い、それ以前はユリウス暦を逆算する。本データセットは 1900 年以降を扱うので切り替えには触れないが、生成器は拡張に備えてその規則を実装している。

## VI、使用の境界（併せてお読みください）

1. **本データセットは暦法の事実のみを収める**——瞬間、年表の項、対応表。**判断も、断語も、吉凶宜忌の指針も、神煞も、特定の個人への言及も含まない。**
2. **A1 の権威順位**：中国国内の標準は紫金山天文台『中国天文年暦』／『暦日資料』（GB/T 33661-2017 に依る）。本データは**独立した第二の出所**であり、復算と長跨度の照会を目的とする。**特定の節気の瞬間を引用するときは、公式の年暦も併せて引用されたい。**
3. **A2 は編纂表であり、原資料ではない**：行用年と編者は二つの公開百科の年表を突き合わせて取る。**歳実などの数値は、出所が明示するもののみを記す**。食い違う 4 点は別に異文として挙げる。**特定の年を引用する前に異文表を参照されたい。**
4. **A3 の日の干支には理論的な誤りがない**（純粋な数えである）。その正しさはアンカーに全面的に依存する。アンカーは 4 件の近現代記録に 1 件の古典記録を加えて交差検証済みである。
5. **A3 の「節気月（月建の支）」は十二の「節」のみで区分する**（立春・驚蟄……小寒）。年干も、五虎遁その他の導出も関与しない。

## VII、復算と再生成

`code/` には三つの生成スクリプトがある（Python 3、`skyfield` と `skyfield-data` を要する）：

| スクリプト | 出力 |
|:---|:---|
| `gen_dataset.py` | A1 二十四節気の交節時刻（紫金山天文台公式値との比較表を含む） |
| `gen_dataset_calendar_reforms.py` | A2 年表と異文表 |
| `gen_dataset_ganzhi.py` | A3 干支紀日表（アンカー検証を含む） |

```bash
python -m pip install skyfield skyfield-data
python code/gen_dataset.py --from 1900 --to 2052 --out . \
    --prev-out "01-二十四节气交节时刻/data/preceding_boundary.csv"
python code/gen_dataset_calendar_reforms.py .
python code/gen_dataset_ganzhi.py --from 1900 --to 2052 \
    --terms "01-二十四节气交节时刻/data/solar_terms_1900_2052.csv" \
    --prev "01-二十四节气交节时刻/data/preceding_boundary.csv" --out .
```

> **`--prev-out` / `--prev` は省けない**：1900 年の最初の五日は 1899 年の冬至がないと節気と月建が定まらず、1900 年から始まる主表にはその行がない。省くと、その五日をその年の小寒に誤って帰属させる。
