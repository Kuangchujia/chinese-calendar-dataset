# A1 · 二十四节气交节时刻（1900—2052）

## 这是什么

公元 **1900—2052 年**、共 **153 年 × 24 节气 ＝ 3,672 条**二十四节气交节时刻，精确到秒。

## 定义

依 **GB/T 33661-2017《农历的编算和颁行》**：

> 二十四节气：一个回归年内 24 个太阳地心视黄经等于 15 度的整数倍的**时刻**的总称。

注意关键词是**时刻**，不是日期。

## 文件

| 文件 | 说明 |
|:---|:---|
| `data/solar_terms_1900_2052.csv` | 主数据表，3,672 行 |
| `data/solar_terms_1900_2052.json` | 同一数据的 JSON 版，header 内含元信息 |
| `data/verification_2026_vs_zijinshan.csv` | 与紫金山天文台 2026 年官方值的逐条比对 |
| `data/preceding_boundary.csv` | **起始年之前最后一个节气**（1899 年冬至，1 行） |

**关于 `preceding_boundary.csv`**：1900-01-01 至 1900-01-05 这 5 天位于 1900 年小寒之前，其「所在节气」应为**1899 年的冬至**。主表自 1900 年起、不含该行，故单列此文件供下游联结（A3 干支表的 `solar_term` 字段用到它）。**若忽略此文件，下游会把 1900 年头 5 天误归到当年的小寒。**

## 字段

| 字段 | 含义 |
|:---|:---|
| `year` | 年份（1900—2052） |
| `term_index` | 节气序号，1—24。1＝小寒，2＝大寒，……，24＝冬至 |
| `term` | 节气名 |
| `solar_longitude_deg` | 该节气的太阳地心视黄经（度），为 15 的整数倍 |
| `beijing_date` / `beijing_time` | 交节时刻，北京时间（UTC+08:00） |
| `utc_date` / `utc_time` | 同一时刻的协调世界时 |
| `jd_utc` | 同一时刻的儒略日（TT 尺度，保留 6 位小数） |

**节气顺序说明**：本表自**小寒**（黄经 285°）起排至**冬至**（黄经 270°），即一个公历年内按日期先后排列。若需按黄经自 315°（立春）起排，按 `term` 名重排即可。

## 算法

1. 取 JPL DE421 星历，用 Skyfield 计算太阳的地心视黄经；
2. **必须用当日真黄道**：`ecliptic_latlon(epoch="date")`。若误用 J2000 历元，会引入**恒定约 8.9 小时**的偏差（2026 年岁差 0.363° 折合太阳行时）。
3. 对每个节气，在该节气所在公历月区间内用二分法求 `黄经(p) − 目标黄经 = 0` 的根，40 次迭代（精度远优于 1 秒）。

## 精度核验

与**中国科学院紫金山天文台《二〇二六年日历资料》**公布的 24 个官方值（北京时间）比对：

| 节气 | 官方值 | 本表推算 | 差（秒） |
|:---|:---|:---|:--:|
| … | 见 `data/verification_2026_vs_zijinshan.csv` | | |

| 指标 | 结果 |
|:---|:---|
| 最大偏差 | **30 秒**（夏至） |
| 平均偏差 | **11.4 秒** |
| 四舍五入到分钟后一致 | **24 / 24** |

> ⚠ **比对的正确姿势**：紫金山天文台公布值**精确到分钟且四舍五入**。拿本表（到秒）直接相减会得到一堆「差 1 分钟」的假失败；**须先把本表值四舍五入到分钟再比**。

## 范围边界

JPL DE421 星历覆盖 **1899-07-28 — 2053-10-08**（实测：2053-12-31 已越界）。为保证全表均为星历内插值、无外推，上界取 **2052**（其冬至在 12 月，仍在覆盖范围内）。

若需 2053 年以后的数据，须改用更长的星历（如 DE440s，覆盖 1849—2150）。

## 引用边界

中国境内的标准来源为紫金山天文台《中国天文年历》／《日历资料》。**本表是独立的第二来源**，价值在于跨度长、精度到秒、算法完全公开可复算。**引用具体节气时刻时，宜同时注明官方历书。**
