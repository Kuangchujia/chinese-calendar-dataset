# A1 · 二十四節気の<ruby>交節時刻<rt>こうせつじこく</rt></ruby>（1900—2052）

**[简体中文](README.zh.md) ｜ [繁體中文](README.zh-Hant.md) ｜ [English](README.md) ｜ 日本語 ｜ [한국어](README.ko.md)**

## これは何か

西暦 **1900—2052 年**、**153 年 × 24 節気 ＝ 3,672 行**の二十四節気の交節時刻を、秒の精度で収めたものである。

## 定義

**GB/T 33661-2017『農暦の編算と頒行』**による：

> 二十四節気とは、一つの回帰年において太陽の地心視<ruby>黄経<rt>こうけい</rt></ruby>が 15 度の整数倍に等しくなる 24 の**時刻**の総称である。

要点は**時刻**であって、日付ではない。

## ファイル

| ファイル | 説明 |
|:---|:---|
| `data/solar_terms_1900_2052.csv` | 主データ表、3,672 行 |
| `data/solar_terms_1900_2052.json` | 同じデータの JSON 版。ヘッダにメタ情報を含む |
| `data/verification_2026_vs_zijinshan.csv` | 紫金山天文台の 2026 年公式値との一件ごとの比較 |
| `data/preceding_boundary.csv` | **開始年の直前の節気**（1899 年の冬至、1 行） |

**`preceding_boundary.csv` について**：1900-01-01 から 1900-01-05 までの 5 日は 1900 年の小寒より前にあり、その「属する節気」は**1899 年の冬至**でなければならない。主表は 1900 年から始まりこの行を含まないため、下流での結合のために別ファイルとして置く（A3 の干支表の `solar_term` フィールドがこれを使う）。**このファイルを無視すると、下流は 1900 年の最初の 5 日をその年の小寒に誤って帰属させる。**

## フィールド

| フィールド | 意味 |
|:---|:---|
| `year` | 年（1900—2052） |
| `term_index` | 節気の番号、1—24。1＝小寒、2＝大寒、……、24＝冬至 |
| `term` | 節気の名 |
| `solar_longitude_deg` | その節気における太陽の地心視黄経（度）。15 の整数倍 |
| `beijing_date` / `beijing_time` | 交節時刻、北京時間（UTC+08:00） |
| `utc_date` / `utc_time` | 同じ時刻の協定世界時 |
| `jd_utc` | 同じ時刻のユリウス日（TT 尺度、小数 6 桁） |

**節気の並び順について**：本表は**小寒**（黄経 285°）から**冬至**（黄経 270°）まで、すなわち一つの暦年内で日付順に並ぶ。黄経 315°（立春）から並べたい場合は、`term` の名で並べ替えればよい。

## アルゴリズム

1. JPL DE421 星暦をとり、Skyfield で太陽の地心視黄経を計算する。
2. **その日の真黄道を使わなければならない**：`ecliptic_latlon(epoch="date")`。誤って J2000 <ruby>暦元<rt>れきげん</rt></ruby>を使うと、**約 8.9 時間の一定のずれ**が入る（2026 年の歳差 0.363° を太陽の運行時間に換算したもの）。
3. 各節気について、その節気が属する暦月の区間内で二分法により `黄経(p) − 目標黄経 = 0` の根を求める。反復は 40 回（精度は 1 秒よりはるかに良い）。

## 精度の検証

**中国科学院紫金山天文台『二〇二六年暦資料』**が公表した 24 の公式値（北京時間）との比較：

| 節気 | 公式値 | 本表の推算 | 差（秒） |
|:---|:---|:---|:--:|
| … | `data/verification_2026_vs_zijinshan.csv` を参照 | | |

| 指標 | 結果 |
|:---|:---|
| 最大のずれ | **30 秒**（夏至） |
| 平均のずれ | **11.4 秒** |
| 分に四捨五入して一致 | **24 / 24** |

> ⚠ **比較の正しい作法**：紫金山天文台の公表値は**分の精度まで、四捨五入されている**。本表（秒まで）から直接引くと、「1 分ずれ」という偽の失敗が並ぶ。**まず本表の値を分に四捨五入してから比べること。**

## 範囲の限界

JPL DE421 星暦の範囲は **1899-07-28 — 2053-10-08**（実測：2053-12-31 はすでに外れる）。全表を星暦内の補間とし、外挿を避けるため、上限は **2052** とする（その冬至は 12 月にあり、なお範囲内である）。

2053 年以降のデータが必要な場合は、より長い星暦に替える必要がある（例：DE440s、1849—2150 を覆う）。

## 引用の限界

中国国内の標準的な出典は紫金山天文台『中国天文年暦』／『暦資料』である。**本表は独立した第二の出典**であり、その価値は、期間が長く、精度が秒に達し、アルゴリズムが完全に公開され復算できる点にある。**個別の節気時刻を引用するときは、公式の暦書も併記するのが望ましい。**
