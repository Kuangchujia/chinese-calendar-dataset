# A1 · 二十四節氣交節時刻（1900—2052）

**[简体中文](README.zh.md) ｜ 繁體中文 ｜ [English](README.md) ｜ [日本語](README.ja.md) ｜ [한국어](README.ko.md)**

## 這是什麼

公元 **1900—2052 年**、共 **153 年 × 24 節氣 ＝ 3,672 條**二十四節氣交節時刻，精確到秒。

## 定義

依 **GB/T 33661-2017《農曆的編算和頒行》**：

> 二十四節氣：一個回歸年內 24 個太陽地心視黃經等於 15 度的整數倍的**時刻**的總稱。

注意關鍵詞是**時刻**，不是日期。

## 文件

| 文件 | 說明 |
|:---|:---|
| `data/solar_terms_1900_2052.csv` | 主數據表，3,672 行 |
| `data/solar_terms_1900_2052.json` | 同一數據的 JSON 版，header 內含元信息 |
| `data/verification_2026_vs_zijinshan.csv` | 與紫金山天文臺 2026 年官方值的逐條比對 |
| `data/preceding_boundary.csv` | **起始年之前最後一個節氣**（1899 年冬至，1 行） |

**關於 `preceding_boundary.csv`**：1900-01-01 至 1900-01-05 這 5 天位於 1900 年小寒之前，其「所在節氣」應為**1899 年的冬至**。主表自 1900 年起、不含該行，故單列此文件供下游聯結（A3 干支表的 `solar_term` 字段用到它）。**若忽略此文件，下游會把 1900 年頭 5 天誤歸到當年的小寒。**

## 字段

| 字段 | 含義 |
|:---|:---|
| `year` | 年份（1900—2052） |
| `term_index` | 節氣序號，1—24。1＝小寒，2＝大寒，……，24＝冬至 |
| `term` | 節氣名 |
| `solar_longitude_deg` | 該節氣的太陽地心視黃經（度），為 15 的整數倍 |
| `beijing_date` / `beijing_time` | 交節時刻，北京時間（UTC+08:00） |
| `utc_date` / `utc_time` | 同一時刻的協調世界時 |
| `jd_utc` | 同一時刻的儒略日（TT 尺度，保留 6 位小數） |

**節氣順序說明**：本表自**小寒**（黃經 285°）起排至**冬至**（黃經 270°），即一個公曆年內按日期先後排列。若需按黃經自 315°（立春）起排，按 `term` 名重排即可。

## 算法

1. 取 JPL DE421 星曆，用 Skyfield 計算太陽的地心視黃經；
2. **必須用當日真黃道**：`ecliptic_latlon(epoch="date")`。若誤用 J2000 曆元，會引入**恆定約 8.9 小時**的偏差（2026 年歲差 0.363° 摺合太陽行時）。
3. 對每個節氣，在該節氣所在公曆月區間內用二分法求 `黄经(p) − 目标黄经 = 0` 的根，40 次迭代（精度遠優於 1 秒）。

## 精度核驗

與**中國科學院紫金山天文臺《二〇二六年日曆資料》**公佈的 24 個官方值（北京時間）比對：

| 節氣 | 官方值 | 本表推算 | 差（秒） |
|:---|:---|:---|:--:|
| … | 見 `data/verification_2026_vs_zijinshan.csv` | | |

| 指標 | 結果 |
|:---|:---|
| 最大偏差 | **30 秒**（夏至） |
| 平均偏差 | **11.4 秒** |
| 四捨五入到分鐘後一致 | **24 / 24** |

> ⚠ **比對的正確姿勢**：紫金山天文臺公佈值**精確到分鐘且四捨五入**。拿本表（到秒）直接相減會得到一堆「差 1 分鐘」的假失敗；**須先把本表值四捨五入到分鐘再比**。

## 範圍邊界

JPL DE421 星曆覆蓋 **1899-07-28 — 2053-10-08**（實測：2053-12-31 已越界）。為保證全表均為星曆內插值、無外推，上界取 **2052**（其冬至在 12 月，仍在覆蓋範圍內）。

若需 2053 年以後的數據，須改用更長的星曆（如 DE440s，覆蓋 1849—2150）。

## 引用邊界

中國境內的標準來源為紫金山天文臺《中國天文年曆》／《日曆資料》。**本表是獨立的第二來源**，價值在於跨度長、精度到秒、算法完全公開可復算。**引用具體節氣時刻時，宜同時註明官方曆書。**
