# A1 · 이십사절기(二十四節氣) 교절 시각(1900—2052)

**[简体中文](README.zh.md) ｜ [繁體中文](README.zh-Hant.md) ｜ [English](README.md) ｜ [日本語](README.ja.md) ｜ 한국어**

## 이것은 무엇인가

서기 **1900—2052년**, **153년 × 24절기(節氣) ＝ 3,672행**의 이십사절기 교절 시각을 초 단위까지 담은 것이다.

## 정의

**GB/T 33661-2017 《농력(農曆)의 편산과 반포》**에 따른다:

> 이십사절기란, 하나의 회귀년(回歸年) 안에서 태양의 지심시황경이 15도의 정수배와 같아지는 24개의**시각**을 아우르는 이름이다.

요점은 **시각**이며, 날짜가 아니다.

## 파일

| 파일 | 설명 |
|:---|:---|
| `data/solar_terms_1900_2052.csv` | 주 데이터 표, 3,672행 |
| `data/solar_terms_1900_2052.json` | 같은 데이터의 JSON판. 헤더에 메타 정보를 담는다 |
| `data/verification_2026_vs_zijinshan.csv` | 자금산천문대 2026년 공식값과의 건별 대조 |
| `data/preceding_boundary.csv` | **시작 연도 직전의 절기**(1899년 동지, 1행) |

**`preceding_boundary.csv`에 대하여**: 1900-01-01부터 1900-01-05까지의 5일은 1900년 소한보다 앞에 있으므로, 그 「속한 절기」는 **1899년의 동지**여야 한다. 주 표는 1900년부터 시작하고 이 행을 담지 않으므로, 하류에서의 결합을 위해 별도 파일로 둔다(A3 간지(干支)표의 `solar_term` 필드가 이것을 쓴다). **이 파일을 무시하면 하류는 1900년의 첫 5일을 그해 소한으로 잘못 귀속시킨다.**

## 필드

| 필드 | 뜻 |
|:---|:---|
| `year` | 연도(1900—2052) |
| `term_index` | 절기 번호, 1—24. 1＝소한, 2＝대한, ……, 24＝동지 |
| `term` | 절기 이름 |
| `solar_longitude_deg` | 그 절기의 태양 지심시황경(도). 15의 정수배 |
| `beijing_date` / `beijing_time` | 교절 시각, 베이징 시간(UTC+08:00) |
| `utc_date` / `utc_time` | 같은 시각의 협정세계시 |
| `jd_utc` | 같은 시각의 율리우스일(TT 기준, 소수 6자리) |

**절기 순서에 대하여**: 이 표는 **소한**(황경(黃經) 285°)에서 **동지**(황경 270°)까지, 곧 하나의 양력 연도 안에서 날짜 순으로 늘어선다. 황경 315°(입춘)부터 늘어세우려면 `term` 이름으로 다시 정렬하면 된다.

## 알고리즘

1. JPL DE421 성력을 가져와 Skyfield로 태양의 지심시황경을 계산한다.
2. **그날의 진황도를 반드시 써야 한다**: `ecliptic_latlon(epoch="date")`. 잘못하여 J2000 역원을 쓰면 **약 8.9시간의 일정한 편차**가 들어온다(2026년 세차(歲差) 0.363°를 태양의 운행 시간으로 환산한 값).
3. 각 절기에 대하여, 그 절기가 속한 양력월 구간 안에서 이분법으로 `황경(p) − 목표 황경 = 0`의 근을 구한다. 반복은 40회(정밀도는 1초보다 훨씬 낫다).

## 정밀도 검증

**중국과학원 자금산천문대 《2026년 역자료》**가 공표한 24개 공식값(베이징 시간)과의 대조:

| 절기 | 공식값 | 본표의 추산 | 차(초) |
|:---|:---|:---|:--:|
| … | `data/verification_2026_vs_zijinshan.csv` 참조 | | |

| 지표 | 결과 |
|:---|:---|
| 최대 편차 | **30초**(하지) |
| 평균 편차 | **11.4초** |
| 분으로 반올림하여 일치 | **24 / 24** |

> ⚠ **대조의 올바른 자세**: 자금산천문대 공표값은 **분 단위까지, 반올림되어 있다**. 본표(초까지)에서 그대로 빼면 「1분 차이」라는 거짓 실패가 잔뜩 나온다. **먼저 본표의 값을 분으로 반올림한 뒤 비교해야 한다.**

## 범위의 한계

JPL DE421 성력의 범위는 **1899-07-28 — 2053-10-08**이다(실측: 2053-12-31은 이미 벗어난다). 전 표를 성력 내 보간으로 두고 외삽을 피하기 위해 상한을 **2052**로 잡는다(그해 동지는 12월에 있어 아직 범위 안이다).

2053년 이후의 데이터가 필요하면 더 긴 성력으로 바꾸어야 한다(예: DE440s, 1849—2150을 포괄).

## 인용의 한계

중국 국내의 표준 출처는 자금산천문대 《중국천문연력》／《역자료》이다. **본표는 독립된 제2의 출처**이며, 그 가치는 기간이 길고 정밀도가 초에 이르며 알고리즘이 완전히 공개되어 다시 계산할 수 있다는 데 있다. **개별 절기 시각을 인용할 때에는 공식 역서(曆書)를 함께 밝히는 것이 좋다.**
