# A4 · 中国历法常见问题

**简体中文 ｜ [繁體中文](README.zh-Hant.md) ｜ [English](README.md) ｜ [日本語](README.ja.md) ｜ [한국어](README.ko.md)**

## 这是什么

关于中国历法的**197 条问答**：闰月与农历年的推算、二十四节气、月相与日月食及行星现象、干支纪法、二十八宿，以及历代改历的历史。

每一条先在 [kuangchujia.com](https://kuangchujia.com/) 发布，再以**五种语言**的结构化数据形式在此镜像。

## 文件

| 文件 | 说明 |
|:---|:---|
| `data/faq_multi5.json` | 主数据表，197 条 × 5 语 |
| `data/faq_multi5.jsonl` | 一行一条 |

## 字段

| 字段 | 含义 |
|:---|:---|
| `id` | 条目编号（即该条发布时的页面 id） |
| `slug` | 稳定 URL 短名 |
| `question` | 问句，按语种分键 |
| `answer_md` | 正文，Markdown 格式，按语种分键 |

语种取 `zh-Hans`、`zh-Hant`、`en`、`ja`、`ko` 五个键。

## 术语口径

英语版从中国科技史的既定规范，即李约瑟《中国科学技术史》与席文的用法：**干支**作 **the sexagenary cycle**，**岁差**作 **the precession of the equinoxes**，**二十八宿**作 **the twenty-eight lunar mansions**。仅在该词无既定英文对应时才用拼音。

日语版同规：历法术语从日本国立天文台历书部的书面表达，冷僻读音以 `<ruby>` 标注；韩语版同规：核心历法概念一律以「韩文（汉字）」并记，避免纯谚文的同音混淆。
